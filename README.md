# 🏠 House Price Prediction System

A professional Machine Learning web application that predicts house prices based on property features using Linear Regression.

---

# 📌 Project Overview

This project uses Machine Learning to estimate house prices based on various house features such as:

- Area
- Bedrooms
- Bathrooms
- Stories
- Parking

The application is built using:

- Python
- Scikit-learn
- Streamlit
- Pandas
- NumPy
